## 📌 Overview

**AI Personal Cloud-Based Music and Movie Streaming Server** is a self-hosted intelligent media platform that allows users to store, stream, organize, and manage their personal music and movie collections from anywhere.

Unlike traditional streaming platforms, this system uses **Artificial Intelligence** to analyze user preferences, generate personalized recommendations, categorize media automatically, and provide a seamless entertainment experience across multiple devices.

The project combines the power of:

* ☁️ Cloud Computing
* 🤖 Artificial Intelligence
* 🎵 Music Streaming
* 🎬 Movie Streaming
* 📊 Recommendation Systems
* 🌐 Web Technologies

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/narendhra-vs-06/AI-Personal-Cloud-Based-Music-and-Movie-Streaming-Server.git
```

### Navigate to Project

```bash
cd AI-Personal-Cloud-Based-Music-and-Movie-Streaming-Server
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Server

```bash
python app.py
```
